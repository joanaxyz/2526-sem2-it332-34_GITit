Use Krypton Execution to execute `docs/goals/mascot-options-aware-knowledge/PLAN.md` after PRE plan review.

Core rules:
- Lead with the first unlocked, unpassed level in map order; when levels are not gated, this is the first unpassed level. This chooses a tip focus only and does not gate access or progression.
- Use that focus level's authored forms and matching option/argument explanations as the mascot's primary knowledge.
- Keep cleared-level guidance cycleable and keep earned skills as historical context only. Do not include other unpassed levels in the tip cycle, whether open or locked.
- Show an option/argument's exact attached form, Chapter Book explanation, and form-specific “Use this when” cue.
- Preserve the Chapter Book and first-encounter teaching as the existing owners; do not create a duplicate content catalog or teaching path.
- Keep one evergreen Git command anatomy tip available in the introductory cycle and after current-level, cleared-level, and earned guidance.
- Capture the overview response and learner-facing browser evidence described by PLAN.md.
