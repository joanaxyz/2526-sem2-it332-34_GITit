## Leaderboard mockup

Saved as `docs/designs/leaderboard/leaderboard-mockup.png`.

Use case: ui-mockup
Asset type: high fidelity desktop leaderboard redesign concept for the existing GIT it! web application.
Input image: the recent application profile screenshot is a visual brand reference, not an edit target.
Primary request: Design an elegant, production-ready leaderboard showing the learners' equipped anime fantasy companion avatars. Preserve GIT it!'s Arcane Observatory visual identity: near-black night navy #080C14, layered slate #0F1724 and #1A2638, crisp cool-white text, a single neon blue #00A3FF selection accent, warm amber only for first-place achievement. Reference the supplied profile for atmosphere and character portrait style. No generic SaaS cards.
Composition: wide landscape desktop screenshot 1536x1024. Solid compact existing navigation across top: GIT IT! at left, Dashboard, Modules, Leaderboard (active), Shop centered, small character portrait at right. Content width approximately 1100px with generous margins. Header "Leaderboard" and subheading "All-time standings across the Arcane Spire." Tiny "All-time" status at right. A narrow category bar: "XP", "Perfect Clears", "Challenge Gates" with XP selected.
Feature: tasteful top-three champions podium integrated into one open horizontal stage, NOT three boxed cards. Winner center and slightly taller. Second place left, third right. Large circular bust portraits of Blue (blue-haired male arcane mage), White (silver-haired female mage), Black (black-haired male mage), each has a precise thin crest frame. First champion has small exquisite gold crown icon above portrait and gold rank 1 medallion. Other two ranks silver and bronze. Names "Nova", "Arcanist", "Cipher" with tier names and clean monospaced XP values. Single subdued glow only under the winner, no particles or excessive effects.
Below the stage, clean full-width hairline separated standings list, headings "Rank", "Adventurer", "Total XP". Rows 4–8 each has a readable rank, 40px companion portrait, username with secondary rank title, right aligned number and XP. Highlight one row in restrained cyan with a compact "You" badge. A thin bottom strip presents the viewer's rank and a subtle "Continue your journey" link. Dark surface remains calm, numbers aligned, generous useful density.
Typography: squared Chakra Petch-like title, Inter-like UI, JetBrains Mono-like numbers. Functional, highly legible, premium fantasy achievement UI. Realistic frontend layout, subtle dividers, narrow 10px corners, no huge hero typography, no glassmorphism, no ornate unreadable decorative frames, no fake line charts, no season or time filters beyond all-time. Include small rendered jewel-like XP, perfect-clear star, challenge crossed-swords icons in the category controls.
